# RGX 操盘系统

> 叶茂中冲突营销嫡传 · 25 年实战沉淀，装进 AI 里的私域与商业操盘大脑。
> 作者：张文昊（昊哥）｜ GitHub：tuoxiaoxiai-del

## 这是什么
RGX 操盘系统是一套面向生意人 / 操盘手的 AI 智能体技能集，覆盖从**定位、选品、内容、流量、直播、私域、成交，到模式与团队**的完整商业链路。它不是一个聊天机器人，而是一支「随叫随到的操盘团队」——你说生意里哪一段卡住了，它按你所处的阶段带你走下一步。

底层方法论来自叶茂中《冲突》理论（作者师从叶茂中），并融合 25 年广告营销与私域实战。

## 包含什么
- `RGX`：总入口。不知道用哪个就描述你的事，它替你路由到正确的子技能。
- 方法论层：`conflict-strategy`（冲突营销）、`ad-os`（广告操作系统）、`emotional-value-strategy`（情绪价值）、`rgx-method`（RGX 方法）
- 私域全链路：定位 / 选品 / 内容 / 流量 / 直播 / 私域成交 / 团队 / AI 流水线 等 40+ 子技能
- 反馈自愈：报问题自动生成反馈卡，持续优化系统

## 安装
需要 WorkBuddy（或兼容的 AI 桌面端）运行环境。

**已购买用户，一行命令安装：**

- macOS / Linux（终端）：
  ```bash
  curl -fsSL https://raw.githubusercontent.com/tuoxiaoxiai-del/RGX/master/install.sh | bash
  ```
- Windows（PowerShell）：
  ```powershell
  irm https://raw.githubusercontent.com/tuoxiaoxiai-del/RGX/master/install.ps1 | iex
  ```

脚本会自动定位 WorkBuddy 技能目录、复制 46 个 RGX 技能，重启即生效。手动方式与故障排查见 [使用指南.md](使用指南.md)。

## 首次使用
启动后它会先和你「聊生意」建档——想到哪说到哪，之后所有判断基于你的真实盘子，不用每次重讲。
