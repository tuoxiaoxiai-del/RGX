## 一、一句话定位

**每个退役军人拿一台新智洗车智能体车 = 一人公司（OPC）+ 社区移动工位 + 智能体网关 + 应急便民终端。**

车辆本身既是创业工具（洗车主线）、又是 OPC 工位（打卡补贴）、又是智能体入口（社区服务）、又是应急终端（AED/灭火/巡防）。四重身份对应四类政策叠加。

## 二、四重身份 × 政策映射

| 车辆身份 | 对应政策 | 可拿（退役军人顶格） |
|---|---|---|
| 创业工具（洗车） | 一次性创业补贴 | 最高 1.5 万（覆盖车成本约 1 万） |
| 创业工具（洗车） | 个体顶格扣减（14号） | 2.4 万/年×3 年（若注册为个体户） |
| 创业工具（洗车） | 创业担保贷款 | 顶格 50 万，免反担保+贴息，累计≤3 次 |
| OPC 工位 | 月补贴 1560/1200/900（军人/大学生，每月） | 3 年合计 72000 元 |
| 社区智能体 | 边缘计算/内容分发 | 未来与字节/金山合作返点（增值，非补贴） |
| 应急终端 | 应急管理部/退役军人事务部立项 | 资质/红头文件优先（非现金） |
| 带岗 | 创业带动就业补贴 | 深圳顶格 3 万 |
| 带岗 | 招用退役士兵定额扣减 | 3 年内按人数扣减（税务） |
| 品牌 | 全国退役军人创新创业大赛 | 获奖解锁多项扶持 |

**合计可量化现金补贴（顶格）**：约 55.2 万 vs 普通创业者 34.0 万，**多拿约 62%**。

## 三、会议里暴露的「模式缺口」——军创 OPC 正好补上

会议反复强调「技术不是问题、资金不是问题，模式是问题」，且具体缺口包括：

| 会议缺口 | 军创 OPC 怎么补 |
|---|---|
| 「60% 给洗车工，但没算模型」 | 军创 OPC 把「洗车工」升级成「一人公司」——60% 不是工资，是**经营利润分成**；一人公司还叠加创业补贴/场租/贷款 |
| 落地运营靠「直营+城市合伙人」 | 军创 OPC 提供**第三路径**：退役军人自主创业，交 3000 押金即可，比合伙人轻、比直营稳 |
| 退役军人「先就业再创业」纠结 | 车 = 工位，街道打卡拿月补贴 1560 元，**既算就业（社保+补贴）又算创业（OPC 补贴+贷款）**，双轨并行 |
| 「广告/洗涤剂/数据/碳汇」四大增值收入没算清 | 这些是**一人公司的增值利润**，不是补贴——按 OPC 主体申报，可叠加研发加计/小微减免，进一步压税 |
| 模式「先质后量」，避免品牌稀释 | 军创 OPC 的**单人单社区独占**（750 台车以上社区投 1 台）天然保证质；复制靠「退役军人×OPC 基地」培训+发证，标准化 |

## 四、落地架构（三方分工）

```
新智洗车智能体项目（索尔旗下孵化）
├── 硬件层：雅迪总装 + 国科新图软件 + 梦想时代洗涤剂
├── 平台层：索尔上市公司（F1 募资 1100 万美金，12月 F3 发一亿股）
├── 资金层：300 亿供应链资金（年化 5–5.5%）+ 中交金融租赁 + 马总/富哥基金
└── 落地层（军创 OPC 切入点）
    ├── 全国 60 万+ 社区资源（福建合作方提供 20 万+）
    ├── 退役军人 OPC 基地（每省 1 个，陈秋工信部发证）
    ├── 街道 OPC 工位（打卡补贴 1560/月）
    └── 雅迪门店 = 维修+OPC 培训基地（本地化）
```

**军创 OPC 在落地层的具体动作**：
1. 每个社区投 1 台车 → 招募 1 名退役军人 → 注册一人公司 → 入驻 OPC 基地
2. 退役军人打卡拿月补贴 + 洗车主线拿 50% 分成（30 元洗→15 元/台）
3. 增值服务（洗涤剂/广告/数据/碳汇）按「增值部分 35/20/20/25」四分配
4. 满 6 个月后申报一次性创业补贴 1.5 万 → 车辆归属 OPC 主体 → 分成逻辑改变

## 五、「车 = 工位」补贴模型（单台车年收益）

```
单台车（社区 750+ 台车）
├── 洗车主线：日均 10-20 台 × 30 元（普通）/50 元（高端）/80 元（精洗）
│   └── 月洗车收入约 1-2 万（取中位数 1.5 万）
│   └── 50% 给退役军人 = 7500/月
│
├── OPC 工位补贴：第1年 1560×12=18720 + 第2年 1200×12=14400 + 第3年 900×12=10800 = 72000 元（3年合计）
│
├── 一次性创业补贴：15000（满 6 个月）
│
├── 带岗补贴（若招 1 名员工）：最高 30000
│
├── 创业担保贷款：顶格 500000（免反担保，贴息）
│
└── 增值收入（洗涤剂/广告/数据/碳汇）
    └── 理想年化 100 万+（30 万台规模下，单台摊薄后约 3-5 千/月）
    
单台车年综合收益（理想）：≈ 15-20 万（洗车）+ 1.87 万（工位第1年）+ 1.5 万（一次性）+ 3 万（带岗）+ 贷款贴息
```

**对退役军人**：低门槛（3000 押金）、无风险（车辆归属 OPC 主体后是自己的）、政策兜底（补贴+贷款双轨）。
**对项目方**：轻资产（设备由投资方/供应链金融覆盖）、标准化（OPC 基地培训+发证）、可复制（全国 60 万社区）。
